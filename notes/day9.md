# VS Code 跑代码的三种方式

| 快捷键 | 作用 | 注意 |
|---|---|---|
| Ctrl + F5 | 跑整个文件 | 每次重开进程，变量清空 ← 验证代码用这个 |
| Shift + Enter | 只跑选中的行 | 跑在 REPL 里，**变量会残留** ← 只用来试语法 |
| Ctrl + ` 然后 ↑ 回车 | 终端重跑 | 输出最真实，报错信息最全 |

坑：Shift+Enter 残留变量，会让你以为代码能跑，其实单独跑就 NameError。

今天学习文件open时一直没有理解为什么我在day9.py里写的代码为什么跑不起来，查询问题后发现时open的问题，一直无法定位到students.csv这个文件，其实是理解错误

懂了，我说一下我的理解你看对不对。我打开的文件夹如果是test2，那么不管我在test2下的几级目录，比如在day9.py里写代码，其实都在test2这个房间里进行操作，想要open某个文件都是从test2开始算，如果我当前所在位置是day9.py和students同级，或者说在test2.py和exercises同级，都需要从test2开始算，想要打开students就得open("exercises/students.csv")对吗。我所在的房间，即位置并不是我现在在编辑或者运行的代码，而是我vscode里打开的最开始的文件夹即根目录

房间 = 运行时所在的目录（cwd），不是你正在编辑的 .py 所在的目录
在 VS Code 里按运行，房间就是你打开的那个文件夹
相对路径都从"房间"开始算，不是从 .py 文件开始算
想要"从 .py 文件旁边算"，就得显式用 Path(__file__).parent
换一种启动方式（比如先 cd），房间就会变，路径就可能失效
