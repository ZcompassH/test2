# 互联网名词解释表 · 小白版

> 用途：**学习前扫一遍建立地图，学习中查，学完用自己的话复述一遍。**
> 优先级：★ 必学（第一年必须懂）｜○ 进阶（工作后慢慢补）｜△ 知道就行（别花时间）

---

## 怎么用这张表（三遍法）

1. **第一遍（现在）**：只看"一句话"和"能做什么"两列，10 分钟扫完，建立全局印象。看不懂没关系。
2. **第二遍（学习时）**：学到哪个词，回来看"包含什么知识"和"怎么学"，对着做。
3. **第三遍（学完）**：遮住"一句话"，用自己的话解释一遍。**讲不出来 = 没学会。**

## B. 后端与 Web

| 名词 | 一句话 | 包含的知识 / 能做什么 | 怎么学 | 和什么联动 | 优先级 |
|---|---|---|---|---|---|
| 客户端 / 服务端 | 客户端是用户用的（浏览器/App），服务端是跑在机房的程序 | 请求-响应模型；所有 Web 应用的基础结构 | 画一张"浏览器→服务器→数据库"的图 | HTTP、API | ★ |
| HTTP / HTTPS | 浏览器和服务器说话的协议；加 S 是加密版 | 方法（GET/POST）、请求头、状态码、加密；能定义接口、排查问题 | MDN + 浏览器 F12 网络面板 | REST、API、Nginx | ★ |
| API | 程序之间约定好的"调用入口" | 接口定义、参数、返回值、鉴权；能做前后端分离、对接第三方 | 自己写一个接口就懂 | REST、JSON、鉴权 | ★ |
| REST 接口 | 一种 API 设计风格：URL 表示资源，HTTP 方法表示动作 | 资源命名、GET/POST/PUT/DELETE、无状态；能设计好维护的接口 | 写 3 个接口后回头看规范 | HTTP、JSON、Spring Boot | ★ |
| JSON | 轻量的数据格式，键值对 | 对象/数组、嵌套、序列化；能前后端传数据 | 10 分钟 | API、REST、数据库 | ★ |
| 请求 / 响应 / 状态码 | 一次网络交互的两端和结果码 | 200 成功、301 跳转、404 找不到、500 服务器错；能排查问题 | F12 看几次就懂 | HTTP、日志、监控 | ★ |
| 路由 | 把不同 URL 分发给不同处理函数 | 路径匹配、参数、中间件；能组织接口 | 写 Spring Controller 时自然懂 | MVC、Spring Boot | ○ |
| MVC | 把代码分成模型/视图/控制器 | 分层、职责分离；能让代码不乱 | 写一个完整增删改查就懂 | Spring Boot、分层架构 | ★ |
| Spring Boot | Java 最主流的后端框架，开箱即用 | 注解、依赖注入、自动配置、Starter；能快速搭一个 Web 服务 | 官方 Guide + 动手做一个 TODO 服务 | Java、MVC、MySQL、MyBatis | ★ |
| ORM / MyBatis | 把数据库表映射成代码对象，少写重复 SQL | 实体映射、SQL 映射、懒加载；能减少数据库样板代码 | 先用 MyBatis 写 XML，再用 MyBatis-Plus | MySQL、Java、Spring Boot | ★ |
| 中间件 | 在请求和业务之间插一层通用处理 | 拦截器、过滤器、限流、日志；能统一处理横切逻辑 | 写一个登录校验拦截器 | Spring、Nginx、消息队列 | ○ |
| 微服务 / 单体 | 单体是一个程序装所有功能；微服务拆成多个小服务 | 服务拆分、注册发现、RPC、网关；能让大团队并行开发 | **先学单体**，工作后再碰微服务 | Docker、K8s、消息队列 | ○ |
| 登录态（Session/Cookie/Token） | 服务器怎么记住"你是谁" | Cookie 存客户端、Session 存服务端、JWT 无状态；能做登录鉴权 | 手写一次完整登录流程 | HTTP、Redis、安全 | ★ |

## C. 数据库与存储

| 名词 | 一句话 | 包含的知识 / 能做什么 | 怎么学 | 和什么联动 | 优先级 |
|---|---|---|---|---|---|
| MySQL | 最流行的开源关系型数据库 | 建库建表、SQL、索引、事务、备份；能存业务数据 | 本地装一个 + DBeaver，边写 SQL 边学 | SQL、索引、Spring Boot | ★ |
| 表 / 行 / 列 / 主键 / 外键 | 关系数据库的基本结构 | 字段类型、约束、表间关系；能设计数据模型 | 设计"用户-订单-商品"三张表 | 索引、JOIN、范式 | ★ |
| 索引 | 让查询变快的数据结构，像书的目录 | B+ 树、联合索引、最左前缀、回表；能把慢查询从秒降到毫秒 | 用 EXPLAIN 看执行计划 | MySQL、SQL 优化、八股 | ★ |
| 事务 / ACID | 一组操作要么全成功要么全失败 | 原子性/一致性/隔离性/持久性、隔离级别、锁；能保证转账不出错 | 写一个转账例子 | MySQL、并发、锁 | ○ |
| JOIN | 把多张表按关系拼起来查 | INNER/LEFT/RIGHT JOIN、笛卡尔积；能多表关联查询 | LeetCode 数据库题 10 道 | SQL、表设计、索引 | ★ |
| Redis / 缓存 | 内存数据库，读写极快 | 键值、过期、持久化、缓存穿透/击穿/雪崩；能做缓存、计数器、排行榜 | 本地装一个，做"查用户先查缓存" | MySQL、性能优化、登录态 | ★ |
| 消息队列 | 生产者发消息、消费者异步处理 | Kafka/RabbitMQ、topic、消费组、幂等；能削峰、解耦、异步 | 先懂概念，工作后再用 | 微服务、Redis、分布式 | ○ |
| 数据仓库 / ETL | 把业务数据抽取清洗后汇总，用于分析 | 维度建模、分层（ODS/DWD/DWS）、调度；能做报表和 BI | 先学 SQL，再看一个数仓分层案例 | SQL、数据开发、BI | ○ |

## D. 网络与部署

| 名词 | 一句话 | 包含的知识 / 能做什么 | 怎么学 | 和什么联动 | 优先级 |
|---|---|---|---|---|---|
| IP / 端口 | IP 是机器的地址，端口是机器上的门牌号 | IPv4、127.0.0.1、常用端口 80/443/3306；能定位服务在哪 | 10 分钟 | 域名、防火墙、部署 | ★ |
| 域名 / DNS | 域名是人记的网址，DNS 把它翻译成 IP | A 记录、CNAME、解析；能让用户用网址访问你的服务 | 买个域名解析一次就懂 | Nginx、HTTPS、备案 | ○ |
| TCP / UDP | 传输层两种协议：TCP 可靠（要握手），UDP 快但可能丢 | 三次握手、四次挥手、拥塞控制；能理解"连接超时" | 面试八股重点 | HTTP、网络排查 | ★ |
| 负载均衡 / Nginx | 把流量分给多台服务器；Nginx 是最常用的反向代理和 Web 服务器 | 反向代理、静态资源、转发规则、限流；能扛高并发、部署前端 | 装 Nginx 配一个反向代理 | 服务器、Docker、HTTPS | ○ |
| 服务器 / 云服务器 | 跑程序的电脑；云服务器就是租的 | CPU/内存/带宽、ECS、安全组；能把项目部署上线 | 买台学生机练手 | Linux、Docker、域名 | ★ |
| Docker / 容器 / 镜像 | 把程序和它的环境打包成"容器"，到哪都能跑 | 镜像、容器、Dockerfile、端口映射、数据卷；能解决"我电脑能跑" | 写一个 Dockerfile 跑起自己的项目 | 部署、K8s、CI/CD | ★ |
| 部署 / 上线 / 回滚 | 把代码放到服务器上让别人能用；出问题退回上一版 | 打包、发布、版本管理；能交付产品 | 手动部署一次就懂 | Docker、CI/CD、监控 | ★ |
| 环境（开发/测试/生产） | 三套独立的运行环境 | 配置隔离、数据隔离；能避免测试影响真实用户 | 知道概念即可 | 配置、部署、CI/CD | ○ |
| CI/CD | 自动构建、测试、部署的流水线 | GitHub Actions / Jenkins、流水线阶段；能提交代码自动上线 | 给 GitHub 项目配一个 Action | Git、Docker、测试 | ○ |

## F. 算法与计算机基础

| 名词 | 一句话 | 包含的知识 / 能做什么 | 怎么学 | 和什么联动 | 优先级 |
|---|---|---|---|---|---|
| 数组 / 链表 | 两种最基础的存数据方式：连续内存 vs 指针串起来 | 随机访问 vs 顺序访问、增删改查复杂度；所有结构的基础 | 各手写一遍 | 哈希表、树 | ★ |
| 栈 / 队列 | 后进先出 vs 先进先出 | push/pop、应用场景（括号匹配、广度搜索）；能做表达式计算、任务排队 | 各手写一遍 | 递归、图遍历 | ★ |
| 哈希表 | 用"键"直接找到"值"的结构 | 哈希函数、冲突处理、扩容；能做字典、去重、缓存 | 手写一个简易 HashMap | Redis、字典、索引 | ★ |
| 树 / 图 | 层级结构 vs 网状结构 | 二叉树、遍历、平衡树、BFS/DFS；能做目录、搜索、路径规划 | 先二叉树再图 | 数据库索引（B+ 树）、地图路径 | ★ |
| 排序 | 把数据按顺序排列的算法 | 冒泡/快排/归并、稳定性；能做排行榜、数据处理 | 能手写快排和归并 | 算法题、ORDER BY | ★ |
| 时间复杂度 | 衡量算法快慢的"量级" | O(1)/O(n)/O(log n)/O(n²)、空间复杂度；能判断代码会不会慢 | 每写一个算法都标一下 | 所有算法题、性能优化 | ★ |
| 递归 / 动态规划 | 自己调用自己；把大问题拆小并记住结果 | 递归出口、状态转移、记忆化；能做树遍历、背包、最短路径 | 先递归后 DP，别硬背 | 树、图、算法面试 | ★ |
| CPU / 内存 / 磁盘 | 计算机三大件：算、临时存、永久存 | 速度量级（纳秒/微秒/毫秒）、缓存层级；能理解程序为什么慢 | 记住速度量级即可 | 性能优化、缓存、数据库 | ○ |
| 进程 / 线程 | 进程是运行中的程序，线程是进程里的执行单元 | 内存隔离、上下文切换、线程池；能理解并发 | 写一个多线程例子 | 并发、锁、JVM | ★ |
| 并发 / 锁 | 多任务同时操作同一份数据，需要锁来排队 | 互斥锁、死锁、乐观/悲观锁；能保证数据不错乱 | 先理解"两个线程同时扣库存" | 线程、事务、Redis | ○ |

## G. 求职黑话
