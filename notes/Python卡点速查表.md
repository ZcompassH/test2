## 1. 字典：计数、取值、排序

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `d = {}` | 空字典 | `[]` 是空列表，`set()` 才是空集合 |
| `d.get(k, 0)` | 取键 k 的值，**没有就返回 0** | 只读，**不创建键** |
| `d[k]` | 读键 k 的值 | 键不存在 → `KeyError` |
| `d[k] = v` | 写入/覆盖键 k | **赋值那一刻才创建键** |
| `count[ch] = count.get(ch, 0) + 1` | 计数标准写法 | 右边先读（假 0），左边后写（真建键） |
| `d.items()` | 变成"键值对列表"，元素是 `(键, 值)` | 只有 `.items()` 才能同时拿到键和值 |
| `for ch, n in d.items():` | 元组解包，拆成两个变量 | 不写 `.items()` 只拿到键，会 `ValueError: not enough values to unpack (expected 2, got 1)` |
| `sorted(d.items(), key=lambda kv: kv[1], reverse=True)` | 按键值对的**值**降序排，返回新列表 | `key` 是"按什么排"；不改原字典；并列时保持原序 |
| `sorted(...)[:10]` | 排序后取前 10 | 切片返回新列表 |
| `dict(pairs)` | 二元组列表 → 字典 | 元素不是二元组 → `ValueError: dictionary update sequence element #0 has length 3; 2 is required` |
| `dict(zip(keys, vals))` | 两个列表拼成字典 | |
| `{w: 0 for w in lst}` | 推导式批量造键 | |
| `Counter(words).most_common(10)` | 计数 + 取前 10（要 `from collections import Counter`） | 和 `sorted(...)[:10]` 等价 |

## 2. 字符串

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `.lower()` | 全部转小写，返回**新**字符串 | 原串不变（字符串不可变） |
| `.strip()` | 去掉首尾空白（含 `\n`） | **只属于字符串**；列表没有这个方法 |
| `.replace(a, b)` | 替换，返回新串 | |
| `.split(",")` | 按分隔符切成列表 | |
| `.isalpha()` | 是不是"全是字母"，返回 `True`/`False` | 空格、标点、数字都是 `False`；中文也算字母 |
| `.isdigit()` | 是不是全是数字字符 | |
| `f"{x}"` | 把变量塞进字符串 | |
| `f"{w:<12}{n}"` | 左对齐占 12 格 | `<` 左对齐、`>` 右对齐、`^` 居中 |
| `r"..."` | 原始字符串，反斜杠不转义 | **写正则一律加 `r`** |

## 3. 数字与运算

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `/` | 真除法，结果**总是 float** | `6 / 2` → `3.0`，不是 `3` |
| `//` | 整除（向下取整） | `-7 // 2` → `-4`（不是 -3） |
| `%` | 取余数 | 判奇偶：`n % 2 == 0` |
| `divmod(7, 2)` | 一次拿到 `(商, 余)` | → `(3, 1)` |
| `range(1, 21)` | 生成 1~20 | **左闭右开**；要 20 就写 21 |
| `range(1-20)` | ❌ 不是"1 到 20" | 先算成 `1-20 = -19` → `range(-19)` 是**空**的，而且不报错 |
| `list(range(1, 21))` | 转成列表看内容 | 验证 range 的利器 |

## 4. 列表

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `lst = []` | 空列表 | |
| `lst.append(x)` | 末尾加**一个**元素 | **返回 None**！改自己，不造新的 |
| `lst.extend([a, b])` | 末尾加**多个** | 等价于 `lst += [a, b]` |
| `lst.insert(i, x)` | 插到下标 i 的位置 | |
| `lst + [x]` | 造一个**新**列表 | 原列表不变 |
| `lst[i]` | 取第 i 个 | 下标从 0 开始 |
| `lst[:10]` | 前 10 个（切片） | 切片永远返回新列表 |
| `len(lst)` | 元素个数 | 数"行数"就是 `len(f.readlines())` |
| `lst.sort()` | 原地排序 | 返回 None |
| `sorted(lst)` | 排序后返回新列表 | |
| `lst.reverse()` / `lst[::-1]` | 原地反转 / 造反转的新列表 | 同上规律 |

> **一句话规律**：改自己的（`append`/`sort`/`reverse`/`extend`）**返回 None**；造新的（`sorted`/`lst+[x]`/`lst[::-1]`）**返回新对象**。

## 5. 函数与变量

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `def f(a):` | 定义函数 | |
| `return x` | 把结果交给调用者 | **不写 return 就等于返回 None** |
| 局部变量 | 函数里定义的变量，出了函数就销毁 | 外面用 → `NameError` |
| 参数 `a` | 函数内的局部名字 | 循环里写 `for a in ...` 会**覆盖参数**，函数就与传入值无关了 |
| `global x` | 声明"我要改外面那个 x" | 能不用就不用；优先 `return` 出去 |
| `list.append` 的返回值 | `None` | `even = list().append(a)` → `even` 是 None，`len(even)` 报 `TypeError: object of type 'NoneType' has no len()` |

## 6. 文件读取（题 7 重点）

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `open(path, encoding="utf-8")` | 打开文件 | Windows 默认编码不是 utf-8，**中文必写** |
| `f.read()` | 一次读成**一个字符串** | 大文件吃内存 |
| `f.readline()` | 读**一行**，返回字符串 | 只读第一行！循环里读才是逐行 |
| `f.readlines()` | **每行读成一个元素**，返回列表 | 列表没有 `.strip()` |
| `for line in f:` | 一行一行读，边读边用 | 省内存；`line` 只是变量名，随便叫 |
| `f.seek(0)` | 回到文件开头 | 迭代器**只能走一遍**，读完再读是 0 行 |
| `with open(...) as f:` | 用完自动关闭 | 比 `f = open()` 安全，异常也能关 |
| `if line.strip():` | 跳过空行 | 用**循环变量**，不是 `lines` |

## 7. 正则（题 8 重点）

| 写法 | 作用 | 坑 / 记忆点 |
|---|---|---|
| `import re` | 导入 | |
| `re.findall(p, text)` | 找出**所有**匹配，返回**列表** | 不是字典！重复和顺序都保留 |
| `re.search(p, text)` | 找**第一个**，返回 Match 或 None | 判断有没有用 `if re.search(...)` |
| `re.sub(p, new, text)` | 替换，返回新字符串 | |
| `re.split(p, text)` | 按模式切分，返回列表 | |
| `[a-z']` | 字符集：小写字母或单引号 | 方括号里是"任选一个" |
| `+` | 前面那个东西出现 1 次或多次 | |
| `[a-z']+` | 一个"词" | 数字、空格、标点自然被排除 |
| `^` | 匹配**字符串开头这个位置** | 零宽断言，不是字符；匹配完第一个后位置就不是 0 了 |
| `$` | 匹配结尾位置 | |
| `\b` | 词边界 | `\b[a-z']+` 和不加结果通常一样 |
| `re.M` | 多行模式，`^`/`$` 按行算 | `re.findall(p, text, re.M)` |

> `re.findall` 第三个参数是 **flags**，不是第二份文本。传错会报 `TypeError: unsupported operand type(s) for &: 'str' and 'int'`。

## 8. 今天原话 → 正确理解

| 你的说法 | 实际情况 |
|---|---|
| "readlines 每一种读成一个元素，挨个读每行" | ✅ 对，是"**每行**读成一个元素"，返回列表 |
| "`dic[i] = ` 是在写入一个键是吗" | ✅ 对，赋值即建键；`dict` 用 `[]` 访问键 |
| "append 是不是没生效" | ❌ 生效了，是它的**返回值**为 None |
| "`^` 只匹配了一次" | ❌ `^` 匹配的是**位置**，只有开头满足 |
| "`range(1-20)` 表示 1 到 20" | ❌ 那是个减法，结果是空的 range，还不报错 |
| "函数里的 evens 外面能用" | ❌ 局部变量，要 `return` |

## 9. 排错三招

1. **`print(type(x))`** —— 不知道它是什么，先问类型
2. **拆开打中间结果** —— `print(count)` → `print(count.items())` → `print(sorted(...))`，看在哪一步变样
3. **读报错最后一行** —— `AttributeError: 'list' object has no attribute 'strip'` 就是在说"列表没有 strip"
